# Personal Portfolio Website — Oasis Infobyte Internship Task 2

A modern, responsive personal portfolio website created as part of the **Oasis Infobyte Web Development and Designing Internship (OIBSIP)**. This portfolio showcases my projects, skills, education, and experience with a clean visual design and interactive user interface.

---

## 🚀 Live Demo

[Click here to view the Live Portfolio Website](https://safinayaqoob13-debug.github.io/OIBSIP-TASK-2-PORTFOLIO/)

---

## ✨ Features

- **Responsive Layout**: Seamlessly adapts to desktop, tablet, and mobile screens.
- **Glassmorphism Design**: Modern, frosted visual theme.
- **Dynamic Navigation**: Sticky navbar with active scroll highlighting and mobile menu.
- **Interactive Form**: Client-side feedback handling on contact form submissions.
- **Projects Showcase**: Visual showcase cards featuring key web applications and links.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic document structure.
- **CSS3**: Custom grid/flexbox, frosted glass visual effects, and responsive media queries.
- **JavaScript (ES6+)**: Event listeners and form interactivity.
